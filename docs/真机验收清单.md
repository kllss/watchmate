# WatchMate 真机验收清单

> 目标设备：REDMI Watch 6。产物：`dist/watchmate-0.1.0.rpk`。
> 逐项勾选，任何失败记录现象（截图/日志）并回填到 `docs/构建与模块验证.md` 的「真机实测」节。

## 0. 安装与启动

- [ ] RPK 通过 AIoT-IDE 安装到手表，无报错
- [ ] 应用图标正常显示，点开不黑屏、不白屏
- [ ] 冷启动进入 Home 页，右上角显示「demo」模式

## 1. 导航与手势

- [ ] Home → Ask → Compose → Settings 可依次跳转
- [ ] Home 的两个大图标入口（问 AI / 设置）点击灵敏、图标清晰
- [ ] 每页左滑/右滑的返回与退出行为符合预期（注意右滑默认退出应用）
- [ ] 表冠滚动在 Ask 回答区可滚动

## 2. demo 模式（不联网先验 UI）

- [ ] Ask 页点「选个问题」展开预设指令，点一条返回 demo 回答
- [ ] 回答多行可滚动，字号足够大、无溢出、无截断
- [ ] 回答中无 Markdown 符号（`#`、`*`、代码块）
- [ ] 大字号在小屏上可读，不显得拥挤

## 3. 自绘键盘（Compose）

- [ ] 点击字母上屏，退格/空格/清空正常
- [ ] 输入拼音出现候选，点候选替换为汉字
- [ ] 切换短语板，点短语上屏
- [ ] 中文与英文/数字之间自动加空格
- [ ] 提交后跳到 Ask 页，问题正确带入并请求

## 4. direct 模式（公网 OpenAI 兼容接口）

- [ ] Settings 切到 direct，选服务商，填 baseUrl/key/model（或构建时注入）
- [ ] 连接测试返回「正常」+ 模型名
- [ ] Ask 提问返回真实回答

## 5. bridge 模式（局域网桥接）

- [ ] PC 上 `node bridge/server.mjs` 启动，手机/手表同网段
- [ ] Settings 填 `http://<PC局域网IP>:8787` + token
- [ ] 连接测试通过
- [ ] Ask 提问经桥接返回真实回答

## 6. 持久化

- [ ] 退出应用重进，设置（模式/服务商/桥接地址）仍在
- [ ] 清缓存后回答缓存被清空

## 7. 边界与稳定性

- [ ] 断网时提问，显示超时/网络错误文案，不卡死
- [ ] 连续快速点击不重复提交（busy 状态拦截）
- [ ] 长时间停留首页无内存增长（观察日志）
